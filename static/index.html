01 / Overview

Data quality, observed during learning.

Classification performance depends heavily on annotation quality. Mislabeled images and ambiguous annotations can degrade model accuracy, while finding these problems manually is resource-intensive.

This work proposes a lightweight, training-time annotation error detection method inspired by information-based sample selection in reinforcement learning. It tracks persistent probability discrepancies across epochs to identify samples whose annotations remain inconsistent with the classifier’s predictions.

The study evaluates the method on CIFAR-100 and Tiny ImageNet with EfficientNet-B1, MobileNetV3-Large, and ResNet-50. The practical goal is to help experts focus their review on a smaller, ranked set of potentially problematic samples. Difficult but correctly labeled images can also receive high scores, so human review remains important.

03 / Get started

Explore the implementation.

The repository contains a PyTorch training pipeline, dataset loaders, per-sample scoring, and ranking export. Run these commands from the project directory using a compatible PyTorch and torchvision installation.

1Clone and install

BASH
git clone https://github.com/kp-labs-bme/dod.git
cd dod
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install requests psutil

The last command installs two packages used by the current implementation but not listed in its requirements file.

2Start a new scoring run

BASH
python train.py \
  --data_loader_use_selection False \
  --callbacks_neptune_logger_callback False \
  --optim_lr_decay False

This uses the current CIFAR-100 defaults, including 1,000 incorrectly labeled duplicates and 1,000 heavily augmented samples. Selection is disabled because the first run has no ranking file. Learning-rate decay is disabled because the current trainer advances its scheduler only with Neptune logging enabled.

For an initial two-epoch trial, append --trainer_n_epochs 2. To omit the added samples, append --data_loader_n_duplicate 0 --data_loader_n_undoable 0. These examples start new experiments; they do not reconstruct the original manuscript runs.

3Inspect the ranking

The default scoring run exports base_exploit_indexes.txt, ordered from the highest score to the lowest. Each line contains sample_index,score,image_path. Review the images before deciding which annotations to correct or remove.

Change the dataset, architecture, scoring method, and experiment settings in configuration.ini. See the README for the available options and implementation notes.
